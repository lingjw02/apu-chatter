# Local personalization implementation plan

Goal: local visual/theme/code editing and per-sender sounds; no server secrets or global account preference changes.
Spec: ../specs/2026-09-21-apu-chatter-design.md
Files: src/features/personalization/{preferences,ThemeSettings,SoundSettings}.tsx, tests via scripts/check-personalization.mjs and browser tests.
Architecture: localStorage namespaced per signed-in user for small presentation/sound mappings; IndexedDB for imported audio blobs. Theme visual controls produce validated CSS tokens. CSS code editor accepts a documented selector/property subset scoped to connected UI, excluding auth/moderation dialogs. Interactive HTML/JS runs only in a sandboxed iframe with opaque origin and restrictive CSP; a source-checked postMessage bridge accepts validated theme-token changes only. Never eval code in the authenticated app. Preview, apply, reset and JSON import/export contain presentation data only.
Theme contracts: accent/background/bubble/text colors, radius, font size; main bubbles/sidebar/header/tabs/composer presentation properties from allowlist, no URL/import/attribute selectors. Invalid CSS gets actionable errors. Advanced sandbox can render custom interactive UI and request token changes; it cannot read real chat, keys, storage or network. Browser-profile local persistence only.
Sounds: mapping per user/group/sender to default/chime/pop/silent/import ID; group mute overrides. Explicit Enable sound gesture unlocks AudioContext. Imported max2MB audio decode validates <=5sec, store in IndexedDB; no uploads. Play only newly observed other-user group messages while open; no historical/pagination playback, no custom background guarantee. Initial live message IDs establish baseline; events call the current local mapping.
Tests: schema/selector rejects injection, token value validation, reset/import roundtrip, sandbox source-check, no external iframe requests, sender/group isolation, mute override, history does not ping, failed audio decode and reduced motion. No claim that browsers support custom sound after the app closes.
